# delegate-to-chatgpt

一个仅在用户显式调用时运行的 Codex Skill，用于把任务委派给当前 ChatGPT 账号里**实际可用的最高性能模型**。

核心原则：

- 只有 `$delegate-to-chatgpt` 会触发，普通复杂任务不会自动触发。
- 不绑定 ChatGPT Pro 或任何固定模型名称；默认从当前模型选择器中选择最高能力选项。
- Codex 始终是总负责人：建立本地事实、准备最小上下文、整合结果并独立验收。
- 外部 ChatGPT 的“测试通过”“已执行”声明不能替代 Codex 的本地验证。
- 未发布源码优先使用最小脱敏源码包，默认阻止常见凭据和敏感文件进入压缩包。

## 使用

```text
$delegate-to-chatgpt review 当前 PR，重点检查架构、并发和测试缺口
```

也可以显式指定当前账号中可选的模型或模式：

```text
$delegate-to-chatgpt 使用 <模型/模式> 分析这个难以复现的并发问题
```

如果指定选项当前不可用，Skill 会改用当前实际可选的最高性能模型，并在最终结果中说明替代情况。

# to-chatgpt

一个仅在用户显式调用时运行的 Codex Skill，用于把任务委派给当前 ChatGPT 账号中用户指定的模型/模式/推理等级；未指定的选择项才默认使用当前实际可用的最高档。

核心原则：

- 只有 `$to-chatgpt` 会触发，普通复杂任务不会自动触发。
- 不绑定 ChatGPT Pro 或任何固定模型名称。
- 模型、模式、推理强度/等级都可以显式指定；某一项未指定时，才对该项选择当前 UI 实际可用的最高档。
- 用户明确指定且当前可用的等级不会因为存在更高等级而被覆盖。
- Codex 始终是总负责人：建立本地事实、准备最小上下文、整合结果并独立验收。
- 外部 ChatGPT 的“测试通过”“已执行”声明不能替代 Codex 的本地验证。
- 未发布源码优先使用最小脱敏源码包，默认阻止常见凭据和敏感文件进入压缩包。

## 使用

未指定模型或推理等级时，使用当前 UI 实际可用的最高档：

```text
$to-chatgpt review 当前 PR，重点检查架构、并发和测试缺口
```

只指定推理等级：

```text
$to-chatgpt 推理强度 <等级> review 当前 PR
```

也可以同时指定当前账号中可选的模型/模式和推理等级：

```text
$to-chatgpt 使用 <模型/模式>，推理强度 <等级> 分析这个难以复现的并发问题
```

如果显式指定的选项当前不可用，Skill 才会使用当前可用的兼容替代项，并在最终结果中说明替代情况；不会仅因为存在更强选项就覆盖一个当前可用的用户指定等级。
